Arduino Wiring Guide
Arduino → HC-05 → Phone
DHT11 DATA → Arduino D2
Soil Sensor AO → Arduino A0
LDR AO → Arduino A1
Relay IN → Arduino D7
HC-05 RX ← Arduino D11 (via voltage divider)
HC-05 TX → Arduino D10

Install AquaRoot
Add to home screen · works offline
📲 Install AquaRoot on Your Phone
1
Open this file in Chrome browser on Android (or host it — see below)
2
Tap ⋮ three-dot menu → "Add to Home screen" or "Install app"
3
Tap "Add" — AquaRoot icon appears on your home screen like a native app!
✅ Web Bluetooth works fully in Chrome on Android.
✅ Once installed, the app opens full-screen with no browser UI.
✅ All sensor data is stored offline in localStorage.
1
Open this file in Safari on iPhone/iPad
2
Tap the Share ⬆ button at the bottom of Safari
3
Scroll and tap "Add to Home Screen" → tap "Add"
⚠ Safari on iPhone does not support Web Bluetooth.
Weather, AI scan, charts, and history all work fine.
For full HC-05 sensor support, use Chrome on Android.
📡 Hosting options (for PWA install)
To get the native "Install app" prompt, the file must be served over HTTPS:
• GitHub Pages — free, upload index.html to a repo
• Netlify Drop — drag & drop the file at netlify.app/drop
• Glitch.com — paste and host instantly for free
• Local network — run python3 -m http.server 8080 on PC, open on phone via your PC's IP
